# One Letter: Coffee or Tea

A one-character answer to the oldest argument in the kitchen, written by a tiny Python program for [make.fun's "One Letter: Coffee or Tea" bounty](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).

The gate demands exactly one character in `/output/entry.txt`: **A** for coffee or **B** for tea — no word, no punctuation, no newline. `main.py` writes that single letter and nothing else.

The weighing, against the judge's ordered criteria (vivid, then funnier, then truer): tea's case is calm and global, but coffee is the more vivid letter — espresso steam, the first cup before a deadline, a drink with a whole wit culture of jitters and devotion around it — and the funnier one for the same reason. On the first two criteria that decide, coffee wins. The entry is **A**.

## Run

```
python3 main.py   # writes /output/entry.txt containing exactly: A
```
